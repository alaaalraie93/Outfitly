# Outfitly 👗👔

تطبيق أندرويد بينسّق ملابسك من خزانتك الشخصية: بتصوّر قطعك، وهو بيقترح أنسب تنسيق، وبيعطيك نسبة توافق، وبيعرض اللبسة على مجسم بيتغيّر حسب طولك ووزنك.

Smart outfit matching from your own wardrobe — Arabic & English, works offline.

## الميزات بالنسخة 1.5

- تصوير القطع مع إزالة الخلفية تلقائياً وكشف اللون (بدون نت)
- إكسسوارات: شنتاية، ساعة، نظارات، قشاط، قبعة، شال، عقد
- اختيار المناسبة: شغل، جامعة، طلعة، عرس، رياضة، سهرة
- تنبيه للقطع المنسية بالخزانة
- تعبئة تلقائية للصنف والنوع والستايل والموسم من الصورة
- لوحة اللبسة: صور قطعك الحقيقية من الراس للإجر أو كولاج
- خزانة مقسّمة: قطع علوية، سفلية، فساتين، أحذية
- تفتح أي قطعة ← بيطلع تحتها أنسب القطع من كل نوع مع النسبة المئوية
- تنسيق يدوي مع نسبة توافق وشرح السبب
- لبسة اليوم حسب الطقس (بالنت) أو حسب الموسم (بدون نت)
- زر عجبتني / ما عجبتني والتطبيق بيتعلم ذوقك
- حفظ اللبسات وسجل شو لبست
- مشاركة لوحة اللبسة كصورة
- تقويم اللبس: شو لبست كل يوم وتخطيط لبسات لقدام
- شنطة السفر: أقل قطع لأكتر لبسات حسب طقس الوجهة
- إحصائيات الخزانة وكلفة كل لبسة
- شو ناقص خزانتي: القطعة يلي بتفتح أكتر لبسات جديدة
- نسخة احتياطية واسترجاع
- واجهة عربي وإنكليزي

## بناء الـ APK على GitHub

الملف `.github/workflows/build-apk.yml` بيبني التطبيق تلقائياً كل ما ترفع تعديل.
بعد البناء بتلاقي `Outfitly.apk` بصفحة **Releases** بالمستودع.

## هيكل المشروع

```
lib/
  main.dart            بداية التطبيق والثيم واللغات
  models.dart          القطع، اللبسات، الملف الشخصي
  state.dart           الحفظ على الموبايل وكل العمليات
  matching.dart        خوارزمية التنسيق ونسبة التوافق
  color_utils.dart     استخراج الألوان وأسماؤها
  weather.dart         الطقس من open-meteo.com
  l10n.dart            النصوص عربي/إنكليزي
  widgets/outfit_board.dart  لوحة اللبسة
  widgets/common.dart      مكونات مشتركة
  screens/             الشاشات
tool/configure_android.sh  اسم التطبيق والأيقونة والصلاحيات
branding/              أيقونة التطبيق
```
